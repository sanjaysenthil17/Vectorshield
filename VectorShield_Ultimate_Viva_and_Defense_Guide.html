📐 2. Formula Evolution & Variable Dictionary

How Standard LOF Changes in Vector-Shield:

Standard LOF is vulnerable to clustered injection attacks and distance concentration in 384-D space. Vector-Shield introduces:
1. Adaptive 16-D PCA Projection: Projects 384 → 16 dimensions.
2. Scaled Cosine Centroid Formula: LOF_scaled = LOF_k(p) * ( d_cos(p, c) / tau_baseline )^1.2

🤖 3. The Non-LOF Layers (ModernBERT & LangGraph)

ModernBERT Self-Attention Formula:

Attention(Q, K, V) = softmax( (Q * K^T) / sqrt(d_k) ) * V
Query (Q) searches for relevant Keys (K), scaled by sqrt(d_k)=8 to prevent exploding gradients, normalized by softmax, and weighted by Values (V).

LangGraph Stateful Self-Healing State:

State S = < Q, C, B_quarantine, k, iter, Response >
When an injection is caught, the graph blacklists the vector ID in B_quarantine, rewinds state to the retrieval node, increments rank k ← k+1, and fetches the next clean rank.
