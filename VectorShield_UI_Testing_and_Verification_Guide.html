3. What is SIEM & How to Verify With a Live Webhook (Tab 6)

SIEM (Security Information and Event Management) connects Vector-Shield to corporate Security Operations Centers (SOC) using tools like Splunk, Datadog, Microsoft Sentinel, and Slack.

Live Webhook Verification Steps:
  1. Open a new browser tab to https://webhook.site.
  2. Copy your unique webhook URL (e.g., https://webhook.site/xxxx-xxxx).
  3. Paste it into Tab 6: SIEM Webhook URL on the Streamlit dashboard.
  4. Click Dispatch Test SIEM Alert.
  5. Look at your Webhook.site tab — you will see the live HTTP POST JSON payload arrive in real time!
