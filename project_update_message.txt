### What the project does (in plain language)
- **Problem**: When you ask a AI‑assistant that pulls information from a knowledge base (a *RAG* system), a malicious user can trick it by injecting hidden prompts ("prompt‑injection").
- **Our solution**: A two‑step guard.
  1. **Fast symbolic filter** – looks at the vector representation of your query and decides if it looks *normal* or *suspicious* using a simple statistical model (Local‑Outlier‑Factor). This runs in a few milliseconds.
  2. **Self‑healing loop** – if the filter says *"quarantine"* we automatically blacklist that vector, ask the retriever for the next‑most‑relevant document, and try again until a safe answer is produced. The whole logic is expressed as a **LangGraph** workflow, so the system can act on its own without a human in the loop.
- **Real‑world data**: We fetch actual attack payloads from NVIDIA’s public *Garak* repo and the Hugging‑Face *prompt‑injections* dataset. No synthetic data is used in the demo.

---
### Who benefits?
- **Enterprises** that want to protect internal AI assistants.
- **AI‑ops engineers** looking for a cheap first‑line defence before they run a heavy neural classifier.
- **Researchers / students** who need a reproducible, open‑source example of a secure RAG pipeline.
